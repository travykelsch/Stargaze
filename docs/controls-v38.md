# Unlimited evades v38

Removed the evade cooldown and countdown display in both layouts. Each 0.30-second roll can be followed immediately by another tap, with no usage limit. An active roll still cannot be stacked or redirected. Direction, distance, collisions, pause, settings and progress are unchanged.

The control runtime suite checks 30 consecutive alternating evades without waiting, rejects stacking, and retains its direction, collision, pause, preference and ship/world checks. Browser animation and physical phone checks remain unavailable.
